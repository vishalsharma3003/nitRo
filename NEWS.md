# nitRo 0.1.0

* First release.
* `nitro()` analyses an R expression, applies automatic fixes, and
  optionally verifies and benchmarks the result.
* `nitro_file()` analyses an R script without running it.
* `list_rules()` lists the 50 rules in nine categories. 13 of them rewrite
  code automatically.
* `get_optimised()` and `get_findings()` extract results; `print()` and
  `summary()` methods for `nitro` objects.
